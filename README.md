# 心情日记 · 情绪日记与自我关怀

一个零门槛的情绪记录与自助疏解小工具，面向学业/职场/社交压力下情绪波动频繁、又缺少低成本疏解渠道的年轻人。

在线体验：见仓库的 GitHub Pages 链接（Settings → Pages）。

## 功能

- **记录情绪**：5 级情绪 + 强度滑块 + 触发因素多选标签（工作学业/人际关系/家庭/健康/财务/睡眠/社交媒体/天气/独处等）+ 文字笔记
- **情绪洞察**：近 7/30 天趋势曲线、35 天情绪日历热力图、触发因素与情绪关联分析
- **自我关怀**：根据最近情绪状态推荐内置可交互呼吸练习（箱式呼吸 / 4-7-8 呼吸）、正念冥想引导、音乐、运动建议
- **历史记录**：搜索、查看、删除、导出 JSON 备份

## 隐私

所有数据仅保存在浏览器本地 `localStorage` 中，不上传到任何服务器，也没有账号系统。

## 技术

纯静态 HTML / CSS / JavaScript，无构建步骤、无第三方运行时依赖，可直接部署到 GitHub Pages 等任意静态托管平台。
